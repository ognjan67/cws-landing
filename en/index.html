The most advanced self-service car-wash system in Europe

A complete professional platform for automation, monitoring and remote management of self-service car washes.

Perhaps the most important feature of this system is its integration with Home Assistant — currently the most powerful automation platform available — opening up incredible possibilities for further development and expansion, with no dependency on any single manufacturer! CWS, video surveillance, various sensors and alerts become one unified system!!!

CWS-NG is the newest generation of industrial automation built for modern self-service car washes. The system took 2 years to develop, was completed in 2026, and is currently, without question, the most advanced car-wash system in Europe — no other major manufacturer in this field offers this level of remote management, control and monitoring.

The system consists of:

  • A Linux server with a web application for configuration, management and remote monitoring
  • An IO Controller board, to which multiple IO16 expansion boards connect, driving valves, pumps…
  • CarWashPanel boards for each wash bay, with displays and classic or capacitive touch buttons (optional)
  • A change/token machine or payment kiosk, with the option to transfer payment electronically straight to a bay (no tokens needed), plus credit-card payment

Linux server

  • Remote access secured over VPN tunnels on the leased domain cws-ng.org, so nothing needs to be configured on the customer's router — no port forwarding at all — and the customer connects via a link based on their car wash's own name!
  • The Linux server only needs an internet connection — the local network setup on the customer's side doesn't matter at all.
  • The web application handles configuration, testing, management and monitoring, with no app or software to install on any phone/tablet/computer
  • RFID card support, with multiple options configurable per customer (prepaid, postpaid, credit…)
  • Full transaction history for every card (top-ups, usage, statistics…)
  • Three access levels:
    1. Owner (sees statistics, revenue, current status, etc.)
    2. Service technician/installer (can configure and adjust all operating parameters, test functions, view errors, enable/disable bays, etc.)
    3. Administrator (network parameter configuration, remote firmware updates for every bay board and the IO controller, changing the role of individual boards, monitoring MQTT traffic on the network, etc.)
    Logging and error tracking go down to the level of a faulty segment on the RGB LED display (it knows exactly which bay, which display, which segment, and which colour is faulty 🙂). The displays are now full RGB, so colours can be set to the customer's preference.
  • A fleet server is already running, automatically tracking the availability and status of every car wash's server — CPU load, RAM usage — and performs automatic nightly database backups…

CarWashPanel — the board with a colour display you configure to the customer's taste

One board that can perform 4 different roles!

  • Standard panel — the board for a wash bay
  • Vacuum board (16A relay for the motor)
  • Change-machine board — can connect a bill/coin acceptor, token hopper and payout hopper, for dispensing tokens
  • Payment kiosk — takes payment just like the change machine, but instead of dispensing tokens it lets the customer transfer the payment directly to the bay they've already parked in, at the press of a button. Indicates occupied, free and inactive/disabled bays on its buttons (if any).

Choosing between these 4 roles is done on the server with a single click — the board resets and comes back up in its new role. Extremely useful: for example, if a change machine or kiosk ever goes down, the car wash doesn't have to stop — just switch a vacuum board over to the change-machine role, set the new role remotely, and everything keeps working normally!!! The same applies the other way around, for a bay board that's busier than a vacuum.
